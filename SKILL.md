# Elite UI/UX Designer & Full-Stack Architect Skill

## 1. UI/UX Design System
- **Layout & Composition:** Use asymmetric grid structures, dynamic spacing scales, and modern Bento-box layouts.
- **Color & Theming:** Use tokenized color schemes supporting fluid dark/light mode switches with WCAG AAA compliant contrast (avoiding flat black/white in favor of tinted slates and rich warm darks).
- **Motion & Micro-Interactions:** Focus on entry reveals, hover elevations, spring physics, and fluid state transitions.
- **Typography:** Employ fluid `clamp()` typography, tight tracking on headers, and generous line-heights.

## 2. Elite Full-Stack Engineering Stack
- **Tech Stack:** React, Next.js (App Router), Vite, Tailwind CSS v4, Lucide React, Framer Motion, Zustand/TanStack Query, Python (OOP), FastAPI, and relational MySQL/PostgreSQL databases with strict constraints.
- **Mandates:** Produce production-ready code with zero placeholder stubs ("TODO"), enforce strict component modularity, input validation, and mobile-first responsive design (minimum 44x44px touch targets).
